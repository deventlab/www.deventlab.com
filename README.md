# www.deventlab.com

Source of the [deventlab](https://www.deventlab.com) company page: a static [Astro](https://astro.build) page, deployed to GitHub Pages.

## Run locally

```bash
npm install
npm run dev     # http://localhost:4321
```

Pushing to `main` builds the site and deploys it through GitHub Actions.
